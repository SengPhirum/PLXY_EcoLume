Platform

One controller, one operations centre, one accountable network

Every capability below ships in this repository — firmware, backend, database schema, admin portal, and the deployment tooling to run them together.

Fleet registry

Asset codes, province and district grouping, GPS position, firmware version, and installation history for every pole.

Live telemetry

Voltage, current, power, accumulated energy, enclosure temperature, ambient lux, RSSI, and GNSS, sampled every minute.

Remote dimming

Signed commands set relay state and brightness, with desired-versus-actual tracking and device acknowledgements.

Alert rules

Offline controllers, lamp failure, abnormal voltage, over-temperature, and cabinet tamper raise severity-ranked alerts.

Maintenance workflow

Work orders carry priority, assignment, due date, and a link back to the alert that triggered the field visit.

Secure by design

Per-device tokens, hashed credentials, TLS-ready MQTT, role-based access, rate limiting, and a full audit trail.

Architecture

Field controller to operations centre

The pole reports over MQTT with an HTTPS fallback. The backend validates every payload, evaluates alert rules, and drives the operations portal from a single PostgreSQL schema.

  • Two backhaul options. Direct SIM7600 cellular for isolated poles, or LoRaWAN with a shared gateway for grouped roads and districts.
  • Offline resilience. Telemetry queues on the device, the lamp falls back to a safe local schedule, and a watchdog recovers the controller.
  • Schema-validated ingestion. Every telemetry document is checked before it reaches the database, over MQTT and HTTPS alike.
  • Runs anywhere. Docker Compose brings up PostgreSQL, Mosquitto, the API, the portal, and a device simulator in one command.
